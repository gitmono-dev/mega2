# storage-only Agent Capture 落库计划（2026-09-11）

**模板版本：** v2；依据 [`plan-template.md`](plan-template.md)，核对日期 2026-09-11。

## 文档职责

本文解决「libra 本机两套 Agent Session（外部 hook 捕获与内部 `libra code` JSONL）无法以 storage-only 形态原样落入 monoengine」的缺口。目标是交付：**仅在 `git.storage_only()` 且 `[agent_capture].enabled=true` 时挂载 `/api/v1/agent-capture`**——独立 ingest token、无用户/OAuth/Cedar 前置；Postgres 元数据（`agent_capture_*`）+ `ObjectNamespace::Agent` 字节；服务器事实源为 **raw**；查询 metadata-first，点进 transcript 返回 raw 并写 access_audit。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点（GC-01），再按任务卡验收。设计讨论稿只作线索；**执行以本文 ADR / 任务卡为准**。

### 适用范围

- `src/config/`：新增 `[agent_capture]`（`enabled`、`tenant_id`、`deployment_id`、配额缺省、`[[agent_capture.ingest_tokens]]`）、`known_fields`、storage-only 校验门。
- `src/callisto/` + `src/jupiter/migration/`：`agent_capture_*` 表、实体、`migrations()` 登记。
- `src/jupiter/storage/` + `src/jupiter/service/`：`AgentCaptureStorage` + `AgentCaptureService`。
- `src/orbit_api/object_storage.rs`：`ObjectNamespace::Agent`。
- `src/ceres/agent_capture/`（新）：ingest token 查找（audience 独立，禁止调用 `lookup_push_token`）。
- `src/api/router/agent_capture_router.rs`（新）+ `src/server/http_server.rs` + `src/api/api_doc.rs`：路由、挂载、OpenAPI。
- `tests/integration_agent_capture.rs`（新）：进程级黑盒。
- 文档：`docs/refactoring/agent-capture.md`（AC-14 同卡产物）、`docs/refactoring/README.md`、`docs/refactoring/integration.md`、`docs/plan/README.md`、`plan-long.md` 索引。

### 非目标

- **不在 review 形态**挂载 `/api/v1/agent-capture`（不注册 → 404）。
- **不实现** libra Mega remote 客户端（写集在 libra 仓，DEFER-AC-01）。
- **不默认**上传 FileHistory 每文件 50 版全文（DEFER-AC-02）。
- **不实现**后台 GC 清扫进程（DEFER-AC-04）；本计划只保证 GC **查询**不以年龄为唯一条件。
- **不实现**脱敏视图、`agent_experts` / runtime `agent_sessions`、计费镜像、Cedar、OAuth、`LoginUser`。
- **不把** session 写入既有 `audit_logs`（`target_id: i64`）。
- **不改** Git smart protocol / LFS / OCI；不复用 `git.push_tokens` / `git.anonymous_access`。
- **不重放** `refs/libra/traces`；不把两套事件合成一条假因果链。

### 成功定义

- storage-only + `enabled=true` + 有效 ingest token：discovery、session upsert、blob staging/finalize、event/file-op/checkpoint ingest、metadata list、raw transcript GET 可用。
- 无 token → 401；token 不覆盖 path → 404；review 或 `enabled=false` → 整棵 404；未挂载时 OpenAPI 不含 `/api/v1/agent-capture`。
- 仅 redacted、无对应 raw blob → `completeness=incomplete`（`missing_raw`）。
- tracing 不含 prompt/token/tool 原文。
- 全部非延后任务卡 `Lifecycle=done` 且 `Acceptance=complete`；计划级 Claude **与** Codex 对本计划文档均为 PASS。

## 已决议设计决策

实现时若需偏离本节，必须先修改计划并说明原因，不得在代码中静默改语义。

### ADR-AC-01: 服务器 PK 叫 `capture_id`；客户 id 只叫 `client_session_id`

- **Status:** Accepted
- **Context:** `server_id` 与 HTTP/主机 server 混淆。libra `{provider}__{provider_session_id}` 只标识本机会话。
- **Decision:** `agent_capture_session.id` 为 `BIGINT GENERATED ALWAYS AS IDENTITY`。对外 JSON 与路径参数一律 **`capture_id`**。libra 复合 id 只出现在 `PUT /repos/{repo}/sessions/{client_session_id}`。子表 FK 列名 `capture_id`。`UNIQUE (tenant_id, repo_id, producer_id, session_kind, client_session_id)`。事件 `UNIQUE (capture_id, event_uid)`。
- **Alternatives considered:** 客户端 id 当全局 PK——拒绝。UUID v7——可后补。
- **Consequences:** 子资源必须先有 PUT 回包中的 `capture_id`。
- **Revisit when:** 需要跨部署联合主键。

### ADR-AC-02: 对象键由服务器派生；含 tenant；客户端不得指定 final key

- **Status:** Accepted
- **Decision:** `ObjectNamespace::Agent` → `as_str()="agent"`。ObjectKey **path**（不再重复 namespace 段）：staging `{deployment_id}/{tenant_id}/staging/{lease_id}`；committed `{deployment_id}/{tenant_id}/{visibility}/sha256/{hex}`。首版 `visibility=raw` 为事实源。`deployment_id`/`tenant_id` 来自配置/token。blob 表 `object_key` 只存服务器值。
- **Alternatives considered:** 客户端提交 key / 跨租户单 CAS——拒绝。
- **Consequences:** 同 digest 不同 tenant 是两行两把 key。
- **Revisit when:** 多区域复制。

### ADR-AC-03: 双重门 + 独立 ingest token；不跟随 `anonymous_access`

- **Status:** Accepted
- **Decision:** `[agent_capture].enabled` 缺省 false。挂载 `git.storage_only() && enabled`。`enabled=true` 且非 storage-only → **config validate 拒绝**。启用后所有 discovery/list/show/ingest 要有效 ingest token（无 token **401**）。token 不覆盖正规化 path → **404**。`[[agent_capture.ingest_tokens]]`：`name`、`token`、`paths`（`token_path_authorizes`）、可选 `tenant_id`（缺省用段级值）。查找为独立函数、sha256 常数时间，**禁止**调用 `lookup_push_token`。`producer_id` = token `name`。`enabled=true` 要求至少一条 token。
- **Alternatives considered:** 复用 push_tokens / 跟随 anonymous_access——拒绝。
- **Consequences:** 运维必须配置 ingest token 才能启用。
- **Revisit when:** DEFER-AC-03。

### ADR-AC-04: 必须收 raw；独立 access_audit / tombstone；不扩 `audit_logs`

- **Status:** Accepted
- **Decision:** Discovery `raw_accepted=true`。仅 redacted 无 raw → `completeness=incomplete`，`partial_reason=missing_raw`。`GET transcript` 返回 raw 并 INSERT `agent_capture_access_audit`。禁止写入 `audit_logs`。tombstone 命中后再 ingest → 409。tracing 只记 id/digest/size。
- **Alternatives considered:** 拒 raw / 扩 audit_logs——拒绝。
- **Consequences:** 持有 ingest token 即能读 raw。
- **Revisit when:** 法律 hold 产品化。

### ADR-AC-05: `repo_id` = 正规化 mega 路径 TEXT

- **Status:** Accepted
- **Context:** 两台 clone → 两个 `libra.repoid`。monorepo 路径常无 `git_repo` 行。
- **Decision:** `/repos/{repo}` 经 `normalize_repo_path` 得到 `repo_id` TEXT。授权、UNIQUE、隔离都用它。`libra_repoid` 可空 metadata，不作 FK/token/object key。
- **Alternatives considered:** `git_repo.id` FK——拒绝（无行则无法 ingest）。
- **Consequences:** 同一 mega 路径共用 `repo_id`；用 `producer_id` 区分实例。
- **Revisit when:** 真实多租户 org 表。

### ADR-AC-06: blob_ref 是 GC 真相；lease 冻结三元组

- **Status:** Accepted
- **Decision:** `agent_capture_blob_ref (blob_id, ref_kind, owner_pk)` UNIQUE；与 owner 同行同事务。禁止单独 `ref_count` 当唯一真相。staging 把 lease 写成 token 的 tenant/repo/producer。finalize 路径必须等于 lease；服务器重算 digest。未过期他方 409。GC 查询：`NOT EXISTS blob_ref AND (lease 空或过期) AND state<>protected`。
- **Alternatives considered:** 只按年龄删——拒绝。
- **Consequences:** 后台 sweeper 为 DEFER-AC-04。
- **Revisit when:** 周期 GC。

### ADR-AC-07: storage-only 可独立使用；无用户列

- **Status:** Accepted
- **Decision:** 表无 `user_id`。`cl_link` 可空且首版不写不查不当授权。`tenant_id`/`deployment_id` 为配置常数。
- **Alternatives considered:** 等 OAuth——拒绝。
- **Consequences:** review 首版不挂载。
- **Revisit when:** DEFER-AC-03。

### ADR-AC-08: file-op 版本化契约；不从 ToolUse JSON 推断

- **Status:** Accepted
- **Decision:** `agent.file_op.v1`。无 `source_event_uid`（或不存在）则拒绝。`op ∈ {read,write,patch,delete,search}`。路径拒 `..`、NUL、绝对路径。digest 非空必须指向已 finalize raw blob。
- **Alternatives considered:** 从 tool JSON 猜字段——拒绝。
- **Consequences:** 客户端必须显式发 file-op 批。
- **Revisit when:** 需要服务端派生。

### ADR-AC-09: JSONL uid 一律 `{generation}:{byte_offset}`；incomplete 一等

- **Status:** Accepted
- **Decision:** JSONL 去重禁止 UUID/tool_call_id/内容 hash。原生 id 进 `native_id`。lifecycle 用 `lifecycle_seq`。`source_stream (capture_id, stream_kind, generation)`。`completeness ∈ {empty,incomplete,complete,truncated}`。未知 kind 存 envelope。FileHistory 不默认 50 版全文。单 session file blob 缺省上限 20。
- **Alternatives considered:** event_id 当 uid——拒绝。
- **Consequences:** jsonl 重写必须升 generation。
- **Revisit when:** 跨 generation 折叠查询。
