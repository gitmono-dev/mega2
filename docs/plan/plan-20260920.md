## 文档职责

本文承接 `plan-20260916` 已定型的出站 SSH / receive-pack 基础设施，实现 **出站同步执行链路**、**`incremental_pack` 硬化（仅 reported 路径）**、**操作授权表面** 与 **create-once 栅栏**。契约事实源是 `docs/refactoring/github-sync.md` 已冻结章节，不是本文件重写语义。

本文只规划任务，不宣称实现完成。

### 适用范围

- 出站 worker、change-set outbox、游标、`have=[last_pushed]`、park / abort / force（Q1–Q5 / Q7）
- `incremental_pack_reported` 与四类预算（Q6a / Q6b）；**不**改直播 clone/fetch `incremental_pack`
- `[[github_sync.operator_tokens]]` 与命令表面（Q7）；本计划**可以**新增 HTTP 路由（60916 ADR-GS-02 只约束 60916）
- `vault_create_once` + `claim_create_once`（Q8）；游标 SQL CAS（非 vault）
- **真实 GitHub live 验收（`DEFER-GS-08` 纳入本计划）**：经 `MEGA_TEST_GITHUB_TOKEN` / `MEGA_TEST_GITHUB_NAMESPACE` 对真实 GitHub 仓库做至少一次 receive-pack 推送并核验 `ok`/`ng`（OX-06）
- 复用 60916 已交付的 SSH / receive-pack 客户端

### 非目标

- 入站 GitHub → mega2（`DEFER-GS-02`）
- mega2 内建合并（ADR-GS-04）
- 改直播 `incremental_pack` / upload-pack ACK（Q6a / Q6b / ADR-GS-06）
- **把 live 验收写成其余卡的绿灯门**：默认/回环卡（OX-01..OX-05）在无 `MEGA_TEST_GITHUB_TOKEN`/`NAMESPACE` 时照常 `complete`（live 门只在 OX-06）
- 修改 `docs/plan/plan-template.md`（`DEP-02`）

### 成功定义

- 绑定路径的 `main` 变更能经 SSH receive-pack 推到配置的 GitHub `remote`，成功判定遵守 GS-15。
- 分歧只 park；force / cursor_reset 仅有 operator token。
- reported pack 遵守 Q6b 预算；未知 client `have` 不变成 upload-pack 错误。
- 金钥自举先 `claim_create_once(ACTIVE_POINTER / ssh_key_ref)` 再 `write_secret`。
- **（OX-06，DEFER-GS-08 纳入）** 在有 `MEGA_TEST_GITHUB_TOKEN` / `MEGA_TEST_GITHUB_NAMESPACE` 时，对真实 GitHub 仓库完成一次 end-to-end receive-pack 推送并核验 GS-15 结果（`ok` 或诊断 `ng`），且不产生不可达的 `blocked`；无 token 时按 `env-not-set` 记退。

## 执行检查必备需求（强制）

**两层凭证是分开的，不得混用。**

- **回环（OX-01..OX-05，层 A）：** 沿用 60916 层 A（无 GitHub token）做本地回环，只用 `.env.test` 的 Postgres/Redis + 进程内 vault + 夹具 SSH 主机钥。这些卡**不要求**、也**不得**把 live 写成绿灯门。
- **live（OX-06，DEFER-GS-08 纳入）：** 真实 GitHub 验收需要 `MEGA_TEST_GITHUB_TOKEN`（PAT）+ `MEGA_TEST_GITHUB_NAMESPACE`（如 `genedna`）。此卡为**唯一 live 门卡**；当两变量缺省或未设时按 `not-run / env-not-set` 记退（不 fail-close 阻塞 OX-01..OX-05 的 `complete`），设置时才要求真实推送核验通过。

> 产品路径（真实部署接 GitHub）仍是层 C 的机器用户 SSH 公钥 + 钉住 `ssh_host_key`（`github-sync.md` 上线检查清单），OX-06 不改变该模型；OX-06 只用测试 PAT/namespace 做一次真实验收，不把 PAT 引入产品读写路径（ADR-GS-03）。
