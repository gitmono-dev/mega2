# monorepo 路径 → GitHub 出站同步执行计划（2026-09-20）

**模板版本：** v2.1。源码核对日期 2026-09-20；tip `1238355`，crate `0.38.18`。

**计划状态（2026-09-20）：** **新建（设计稿，0 实现）**。由 `plan-20260916` GS-10 建档。五张 spike 全部 **go**，本计划整体承接 `DEP-01`。实施按本文件任务卡另开，不在 GS-10 会话落地。

## 文档职责

本文承接 `plan-20260916` 已定型的出站 SSH / receive-pack 基础设施，实现 **出站同步执行链路**、**`incremental_pack` 硬化（仅 reported 路径）**、**操作授权表面** 与 **create-once 栅栏**。契约事实源是 `docs/refactoring/github-sync.md` 已冻结章节，不是本文件重写语义。

本文只规划任务，不宣称实现完成。

### 适用范围

- 出站 worker、change-set outbox、游标、`have=[last_pushed]`、park / abort / force（Q1–Q5 / Q7）
- `incremental_pack_reported` 与四类预算（Q6a / Q6b）；**不**改直播 clone/fetch `incremental_pack`
- `[[github_sync.operator_tokens]]` 与命令表面（Q7）；本计划**可以**新增 HTTP 路由（60916 ADR-GS-02 只约束 60916）
- `vault_create_once` + `claim_create_once`（Q8）；游标 SQL CAS（非 vault）
- 复用 60916 已交付的 SSH / receive-pack 客户端

### 非目标

- 入站 GitHub → mega2（`DEFER-GS-02`）
- mega2 内建合并（ADR-GS-04）
- 改直播 `incremental_pack` / upload-pack ACK（Q6a / Q6b / ADR-GS-06）
- 产品路径 `gh` / GitHub REST（ADR-GS-03）
- 真实 GitHub live 验收仍延后到本计划实现链路之后（`DEFER-GS-08`）
- 修改 `docs/plan/plan-template.md`（`DEP-02`）

### 成功定义

- 绑定路径的 `main` 变更能经 SSH receive-pack 推到配置的 GitHub `remote`，成功判定遵守 GS-15。
- 分歧只 park；force / cursor_reset 仅有 operator token。
- reported pack 遵守 Q6b 预算；未知 client `have` 不变成 upload-pack 错误。
- 金钥自举先 `claim_create_once(ACTIVE_POINTER / ssh_key_ref)` 再 `write_secret`。
