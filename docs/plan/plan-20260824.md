## 文档职责

本文解决「`crates/orbit-api` + `crates/orbit` + `bin/` 瘦二进制注入」三 crate 拓扑下的对象存储拆分问题：将 orbit 契约与实现**全部迁入**根 package 的 `src/orbit_api/` 与 `src/orbit/`，移除 `ObjectStorageProvider` 进程级注册表，并把 workspace 收成**单一 package**（`[lib]` + `[[bin]]`）。

本计划**刻意逆转** `docs/refactoring/orbit.md` 中「core 只依赖 orbit-api、实现由 bin 注入」的编译隔离策略，换取目录统一与构造路径简化；运行期对象存储语义（4 后端、`ObjectStorageFactory::build` 逻辑、`MegaObjectStorageWrapper` trait 边界）必须保持不变。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点，再按任务卡验收。

### 适用范围

- `crates/orbit-api/src/**` → `src/orbit_api/**`
- `crates/orbit/src/**`（含 `adapter/`、`factory.rs`）→ `src/orbit/**`
- `src/jupiter/storage/object_storage.rs` 注入层移除
- `bin/` 子包退场 → 根 `[[bin]]` + `tests/**`
- 工程文档与 CI `paths:` 过滤器

### 非目标

- **不**改变 `MegaObjectStorage` / `LogStorage` trait 方法签名、`ObjectKey::default_sharding`、`ObjectNamespace` 字符串值。
- **不**改变 Postgres schema、HTTP API、CLI 子命令、配置字段语义。
- **不**将 `object_store` 云 SDK 再次从主编译图剥离。
- **不**发布独立 `orbit-api` crate（`DEFER-ORB-01`）。

### 成功定义

- `crates/orbit/`、`crates/orbit-api/`、`bin/` 目录删除；workspace 仅根 package。
- 根 `[package] name = "monoengine"`，`[lib] name = "monoengine_core"`，`[[bin]] name = "monoengine"`；单一 `version` 字段。
- 限定守卫：`(?<!crate::)\borbit_api::` 与 `(?<!crate::)\borbit::` 在 `src/` 零命中；`ObjectStorageProvider|OBJECT_STORAGE_PROVIDER|set_object_storage_provider` 在 `src/` 零命中。
- `source .env.test && cargo test --all` 全绿；`docs/refactoring/orbit.md` 标记已由本计划取代。

## 已决议设计决策

### ADR-ORB-01: 完全单体内联，撤销 orbit provider 注入边界

- **Status:** Accepted
- **Decision:** `src/orbit_api/` + `src/orbit/`；`build_object_storage` 直连 `crate::orbit::factory::ObjectStorageFactory::build`；修订 `plan-long` 原则 2。
- **Revisit when:** 编译时间成为瓶颈。

### ADR-ORB-02: 单 package 命名为 `monoengine`，lib 名为 `monoengine_core`

- **Status:** Accepted
- **Decision:** 合并后 `[package] name = "monoengine"`，`[lib] name = "monoengine_core"`，`[[bin]] name = "monoengine"`。

### ADR-ORB-03: 模块布局与可见性

- **Status:** Accepted
- **Decision:** `mod orbit_api;` + `pub mod orbit;`（实现模块对 composition root 可见）；`orbit` 内 `adapter` 保持 `pub(crate)` 或私有；业务模块仍只经 `MegaObjectStorageWrapper` 交互（GC-ORB-02）。
- **Transition:** ORB-02 完成后 `bin` 改 `monoengine_core::orbit::factory::...`；ORB-04 创建 `src/main.rs` 后同路径；ORB-06 起 package 名 `-p monoengine`。

### ADR-ORB-04: 版本递增为 minor

- **Status:** Accepted
- **Context:** ORB-03 删除 `pub use set_object_storage_provider`；ORB-04..06 删除 `monoengine-core` / `orbit` / `orbit-api` 独立 package 面。
- **Decision:** ORB-09 使用 `minor`（预期 `0.3.0`）。本仓无对外发布的 Rust library crate，但 workspace 包名与 embedder 路径变更仍属破坏性 Cargo 面。
- **Alternatives considered:** patch — 拒绝（低估包/导出删除）。
